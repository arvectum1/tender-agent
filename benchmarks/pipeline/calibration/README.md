# Calibration gate

The initial calibration set is deliberately capped at three procurements already
reviewed with the Product Owner: two Cybox cases and the RSL case referenced by
issue #52.

No old chat analysis, prior report, manual ranking, or previously extracted fact
may be copied into a blind label. Each case starts from original public source
materials freshly imported through the same accepted Tender Agent collection
path that the benchmark will use later.

Run one case first. Inspect all artifacts and the review routing before importing
case two. Stop immediately on any evaluator leak, digest inconsistency, schema
failure, unclassified material comparator result, or unexpected review-state
transition. Only after cases 1–3 are clean should a separate task consider the
30–50 case corpus.

Real procurement archives and operator logs are local calibration artifacts and
must not be committed to this repository.
